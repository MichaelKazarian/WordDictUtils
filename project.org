** Загальний опис проекту
. [Цей проект](https://github.com/MichaelKazarian/WordDictUtils) призначено для створення словників для проекта [WordDolphin](https://play.google.com/store/apps/details?id=com.waverunner.wordrunner).
Основа проекту мій інший проект, [WordDictCore](https://github.com/MichaelKazarian/WordDictCore) який презентує відкритий формат для зберігання слів для додатку WordDoplhin.
Словники будуть створюватись через утіліти командного рядка. ось pom.xml Для WordDictUtils. Залежить від

**  Призначення проекту
Проект WordDictUtils — це набір утиліти командного рядка, призначених для:

Генерації словників у форматі .wdi (відкритий формат WordDictCore)
Конвертації даних з зовнішніх джерел (Wiktionary, CSV, JSON тощо) у формат WordDolphin
Валідації та перевірки цілісності словників
Оптимізації та стиснення словників
Підтримки багатомовних словників (EN→UK, UK→EN, тощо)

Словники, створені за допомогою цих утиліт, використовуються у мобільному додатку WordDolphin.

*** Менеджер словників
**** Загальна концепція
Необхідний верхній рівень управління словниками (файлова система, БД тощо).
Цей рівень дозволяє працювати з кількома вихідними базовими мовами одночасно і описується класом Baselanguage.
Вихідна мова (source) → цільова мова (target).
Для кожної базової мови можна мати багато словників у різні цільові мови, включно з кількома іменованими словниками на одну й ту саму пару.
**** Модель словника
 Клас Dictionary представляє словник для конкретної мови:
 Наприклад, англійсько-український словник містить англійські слова з українськими перекладами.
 Усі операції зі словами нечутливі до регістру.

**** Структура каталогів (файлова реалізація)
#+BEGIN_SRC
dictionaries/                           ← глобальний корінь
├── en/                                 ← BaseLanguage = "en"
|   ├── --stats                         ← Статистика
│   │   ├── de                          ← по мовам
│   │   ├───── A.json
│   │   └───── Z.json
|   ├── --sounds/                       ← Аудіо спільне для всіх словників базової мови
│   ├── uk/                             ← стандартний словник en→uk (без власної назви)
│   │   ├── description.json
│   │   ├── words/
│   │   └── sounds/
│   ├── uk_MyMinimal/                   ← іменований словник en→uk
│   ├── uk_Personal2025/
│   ├── fr/
│   ├── fr_Business_Vocabulary/
└──es/                                  ← baseLanguage = "es"
    ├── en/
    └── de/
#+END_SRC
Правила іменування словників у межах однієї baseLanguage:
якщо назва не вказана → папка = код цільової мови (uk, de, fr …)
якщо назва вказана → папка = {targetCode}_{dictionaryName} (uk_Minimal, fr_Business_Vocabulary тощо)
Унікальність словника визначається кінцевою назвою папки всередині папки baseLanguage.

**** Структура каталогів відображається так:
Структура каталогів в коді віжображається так:
DictionaryManager          ← глобальний, один на всю програму
   └── List<BaseLanguage>  ← кожна — одна вихідна мова (en, es, uk…)

**** Класи, які вже задіяні в поточній архітектурі менеджеру словників

com.worddict.worddictcore.Language 
 — опис мови (код ISO-639-1, назва англійською, локальна назва, рейтинг)
com.worddict.worddictutils.DictionaryManager
 - Глобальний менеджер — один екземпляр на всю програму (Singleton)
 - Тримає список усіх BaseLanguage (en, es, uk, de…)
 - Єдина точка входу для доступу до будь-якого словника
 - Методи: addBaseLanguage(), getBaseLanguages(), getBaseLanguage(code)
com.worddict.worddictutils.DictionaryManagerFileSystem:
 - Ралізує DictionaryManager в об'єктах файлової системи
com.worddict.worddictutils.BaseLanguage
 - Абстрактний клас представляє одну базову мову — наприклад, англійську
 - Керує всіма словниками, що мають цю мову як source
 - Методи: createDictionary(…), listDictionaries(), removeDictionary(…)
com.worddict.worddictutils.BaseLanguageFileSystem extends BaseLanguage
 - реалізує BaseLanguage в об'єктах ФС
com.worddict.worddictutils.Dictionary
 — Базовий (abstract) клас одного конкретного словника.
 - Відповідає за операції з словами, аудіо, статистикою:
   - Перевірка чи існує слово.
   - Додавання, редагування, видалення слова.
   - Додавання та видалення аудіо до слова.
   - Пошук слова використовуючи com.worddict.wiktionarybot
   - Оперує екземплярами com.worddict.worddictcore.Word
com.worddict.worddictutils.DictionaryFileSystem extends Dictionary
 - Реалізує Dictionary на базі файлової системи.

*** CLI Модуль add-word
Реалізувати консольну команду для створення або повного перезапису файлу слова у форматі JSON.
Програма має автоматизувати маппінг аргументів командного рядка в об'єктну модель =Word=
та забезпечити синхронізацію аудіо-активів.

**** ФОРМАТ ВИКЛИКУ
#+BEGIN_SRC bash
worddict add-word <DICTDIR> <SRC> <TARGET> <WORD_TEXT> [OPTIONS]
#+END_SRC

**** Позиційні параметри
- *DICTDIR* :: Шлях до кореня сховища (де знаходяться папки мов).
- *SRC* :: Код вихідної мови (наприклад, ~en~).
- *TARGET* :: Код цільової мови (наприклад, ~uk~).
- *WORD_TEXT* :: Текст слова, що додається (наприклад, "table").

**** ПАРАМЕТРИ ТА ОПЦІЇ (Picocli)
| Ключ      | Опис               | Формат значення (Роздільник ~;!;~)       | Обов'язковий |
|-----------+--------------------+------------------------------------------+--------------|
| -i, --ipa | Транскрипція       | Рядок                                    | Ні           |
| -n, --note| Загальна нотатка   | Рядок                                    | Ні           |
| -ex       | Глобальні приклади | ~ex1;!;ex2~                              | Ні           |
| -s        | Звукові файли      | ~path/to/file1;!;path/to/file2~          | Ні           |
| -t        | Блок перекладу     | ~переклад;!;приклад1;!;приклад2~         | Так (мін. 1) |

**** БІЗНЕС-ЛОГІКА (Алгоритм обробки)
***** Керування Аудіо [-]
  - [ ] Розбити значення ключа =-s= за роздільником ~;!;~.
  - [ ] Для кожного шляху перевірити фізичну наявність файлу.
  - [ ] Визначити цільову папку: ~$(DICTDIR)/$(SRC)/--sounds/~.
  - [ ] Якщо локальний файл існує і його немає в цільовій папці -> *Копіювати*.
  - [ ] До об'єкта =Word= записати лише /Filename/ (без повного шляху).

***** Маппінг Об'єкта Word [-]
  - [ ] Створити екземпляр класу =Word=.
  - [ ] Парсинг =-t=: перший елемент — значення ~translation~, наступні — список ~examples~.
  - [ ] Прив'язати глобальні приклади (~-ex~) та нотатку (~-n~).
  - [ ] Додати список звукових імен до об'єкта.

***** Збереження на диск [-]
  - [ ] Використати логіку =DictionaryFileSystem= для генерації шляху.
  - [ ] Шлях: ~$(DICTDIR)/$(SRC)/$(TARGET_DIR)/${WORD[0]}/$(WORD).json~.
  - [ ] *Важливо:* Якщо файл існує — повністю перезаписати (Overwrite).

**** ПРИКЛАД ВИКОРИСТАННЯ
#+BEGIN_SRC bash
worddict add-word ./storage en uk "spring" \
  -i "sprɪŋ" \
  -s "./raw/spring_us.mp3;!;/sounds/spring_uk.wav" \
  -ex "The spring of 2024;!;Water from the spring" \
  -t "весна;!;Spring is here;!;Spring is in the air" \
  -t "пружина;!;The spring is broken" \
  -n "Has multiple meanings"
#+END_SRC
